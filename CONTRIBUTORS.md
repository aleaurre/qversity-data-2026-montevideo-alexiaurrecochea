## How to contribute

This repository is a closed submission for evaluation, not an open-source
project. Issues and pull requests are not actively monitored. If you found
this code via a public link and want to reuse parts of it under the MIT
license, you are welcome to — but please open your own fork rather than
expecting changes upstream.
